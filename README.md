# 🤖 AI Informer Chatbot

An AI-powered web chatbot that provides real-time information by integrating external REST APIs. The chatbot features a clean, responsive interface and delivers fast, interactive responses to user queries across multiple topics.

## 🚀 Features

- Real-time information retrieval using REST APIs
- Interactive chatbot interface
- Responsive design for desktop and mobile devices
- Dynamic content rendering
- Error handling for failed API requests
- Loading indicators for better user experience
- Fast and lightweight frontend
- Easy-to-use conversational interface

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### APIs
- REST APIs

### Deployment
- Vercel

### Clone the Repository

```bash
git clone https://github.com/NizamUddin988/Informer-Chatbot-.git
```

### Navigate to the Project

```bash
cd Informer-Chatbot
```

### Run the Project

Simply open:

```text
index.html
```

or use **VS Code Live Server** for a better development experience.

## 🔗 API Configuration

Replace the API URL and API key (if required) inside your JavaScript file.

Example:

```javascript
const API_URL = "YOUR_API_ENDPOINT";
const API_KEY = "YOUR_API_KEY";
```
